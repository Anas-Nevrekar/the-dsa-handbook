88. Merge_Sorted_Array
Difficulty: Easy
1. Problem Understanding
a. We are given two sorted integer arrays, nums1 and nums2.
b. nums1 has 'm' initial elements and 'n' empty slots at its end.
c. nums2 has 'n' elements.
d. The task is to merge all elements from nums2 into nums1.
e. The final nums1 should contain all 'm + n' elements in a single sorted order.

2. Approach
a. The solution uses a two-pointer approach, starting from the end of both arrays.
b. It compares the largest available elements from nums1 and nums2.
c. The larger element is placed at the current end of the merged array in nums1.
d. This prevents overwriting elements in nums1 that have not yet been processed.

3. Algorithm Steps
a. Initialize a pointer 'k' to 'm + n', representing the total elements to place and the next available position to fill from the end.
b. Loop while 'k' is greater than 0, meaning there are still elements to place.
c. If all elements from nums2 have been placed (indicated by 'n' being 0), then the remaining elements in nums1 (from its original 'm' part) are already in their correct sorted positions. So, decrement 'k' to account for them.
d. Else if all original 'm' elements from nums1 have been considered (indicated by 'm' being 0), take the largest remaining element from nums2 (at 'nums2[n-1]'). Place this element at 'nums1[k-1]', then decrement 'k' and 'n'.
e. Otherwise (both 'm' and 'n' are greater than 0), compare the largest remaining element in nums1 (at 'nums1[m-1]') with the largest remaining element in nums2 (at 'nums2[n-1]').
f. Place the larger of these two elements into 'nums1[k-1]'.
g. Decrement 'k' and the pointer ('m' or 'n') corresponding to the array from which the element was taken.
h. The loop continues until all 'm + n' elements have been correctly placed in nums1.

4. Time Complexity
O(m + n)

5. Space Complexity
O(1)
