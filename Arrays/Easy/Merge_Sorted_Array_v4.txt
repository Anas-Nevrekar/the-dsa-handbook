88. Merge_Sorted_Array
Difficulty: Easy
1. Problem Understanding
a. You are given two sorted integer arrays, nums1 and nums2.
b. nums1 has m initialized elements and enough empty space at its end to hold all elements from nums2.
c. nums2 has n initialized elements.
d. The goal is to merge nums2 into nums1 so that nums1 contains all elements from both arrays in a single sorted list.
e. The merge must be done in-place within the nums1 array.

2. Approach
a. The solution uses a two-pointer approach, starting from the end of both arrays and the end of the target array nums1.
b. It fills nums1 from right to left (from the largest index to the smallest).
c. By comparing the largest remaining elements from the initial parts of nums1 and nums2, it places the larger one into the correct final position in nums1.
d. This strategy avoids overwriting elements in nums1 that have not yet been processed, as we write into the empty space at the end of nums1.

3. Algorithm Steps
a. Initialize a pointer 'k' to point to the last position in nums1 where the merged element will be placed, which is 'm + n - 1' (or `m+n` if using `k-1` for indexing).
b. Initialize 'm' and 'n' to represent the current last valid index of the original elements in nums1 and nums2 respectively (effectively, their counts).
c. Start a loop that continues as long as 'k' (the current target index in nums1) is greater than 0.
d. Inside the loop, first check if all elements from nums2 have been considered (if 'n' is 0). If so, it means any remaining elements in nums1 are already in their final sorted positions, so we just decrement 'k' and continue.
e. Next, check if all elements from the original part of nums1 have been considered (if 'm' is 0). If so, copy the current largest remaining element from nums2 (at index 'n-1') into nums1 at position 'k-1', then decrement 'k' and 'n'.
f. If both 'm' and 'n' are greater than 0, compare the element at nums1[m-1] with nums2[n-1].
g. If nums1[m-1] is greater than or equal to nums2[n-1], copy nums1[m-1] to nums1[k-1], then decrement 'k' and 'm'.
h. Otherwise (if nums2[n-1] is greater), copy nums2[n-1] to nums1[k-1], then decrement 'k' and 'n'.
i. The loop continues until 'k' becomes 0, at which point all elements are merged and nums1 is sorted.

4. Time Complexity
O(m + n)

5. Space Complexity
O(1)
